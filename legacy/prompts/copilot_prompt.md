## Статус данных (ВАЖНО)
Первичный анализ данных, очистка и структурирование уже выполнены заранее.

Используется готовый аналитический датасет:
- формат: wide (1 строка = 1 год, столбцы = показатели)
- период: 2015–2024 гг.
- файл: `agro_dataset_ml_renamed_v2.csv`
- повторную очистку, reshaping или переименование столбцов НЕ выполнять

## Единицы измерения и масштабирование данных (ВАЖНО)

Датасет содержит показатели, измеряемые в РАЗНЫХ шкалах:

- Денежные показатели: млн тенге (`gross_output`, `investment_agri`, `net_profit`)
- Относительные показатели: проценты (`*_rate`, `*_share`, `profitability`)
- Количественные показатели:
  - тыс. человек (`employment_total`, `employment_women`)
  - млн гектаров (`agri_land_area_mha`)

При построении моделей:

- НЕ приводить данные к единой шкале без обоснования
- Масштабирование (StandardScaler) использовать ТОЛЬКО:
  - для ML-моделей (Ridge / Lasso / ElasticNet)
  - внутри pipeline или после разделения данных
- Для эконометрических моделей (OLS / ARDL / ECM):
  - использовать исходные шкалы
  - интерпретировать коэффициенты с учетом единиц измерения

При визуализации:
- единицы измерения выносить в подписи осей (ylabel)
- не смешивать показатели разных шкал на одном графике

## Цель исследования
Построить прогноз **валового выпуска продукции (услуг) сельского хозяйства**
на основе многомерных годовых социально-экономических и производственных показателей.

Целевая переменная:
- `gross_output`

## Методологические ограничения
- Использовать только интерпретируемые модели
- Не использовать глубокие нейросетевые модели
  (LSTM, GRU, Transformers, нейронные сети)
- Избегать «чёрных ящиков»
- Делать акцент на интерпретируемость,
  экономический смысл и сценарный анализ

## Фокус реализации (следовать notebook_structure.md)
- Эконометрические модели: OLS, ARDL, ECM (упрощённая форма)

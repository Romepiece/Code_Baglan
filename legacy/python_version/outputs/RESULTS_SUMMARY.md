# Результаты Прогнозирования Сельскохозяйственного Производства Казахстана (ОБНОВЛЕНО)

**Проект:** Сценарное прогнозирование валовой продукции (gross_output) до 2030 года  
**Период данных:** 2015–2024 (10 наблюдений)  
**Целевая переменная:** `gross_output` (млн тенге)  
**Дата анализа:** 17 января 2026
**Статус:** ✅ Исправлено (консервативные сценарии + ARIMA)

---

## 📊 Основные Характеристики Датасета

- **Количество наблюдений:** 10 лет (2015-2024)
- **Количество признаков:** 15 факторов
- **Размер финального датасета:** 8 наблюдений (после удаления пропусков в `gov_support_index`)

### Используемые Факторы

Для моделирования были отобраны 6 ключевых факторов:

1. **investment_agri** — Инвестиции в сельское хозяйство (млн тенге)
2. **labor_productivity** — Производительность труда (тыс. тенге/чел)
3. **employment_total** — Общая занятость в сельском хозяйстве (тыс. чел)
4. **gov_support_index** — Индекс государственной поддержки
5. **profitability** — Рентабельность (%)
6. **net_profit** — Чистая прибыль (млн тенге)

---

## 🎯 Используемые Модели

В исследовании применены **6 моделей**:

### 1. **OLS (Ordinary Least Squares)** — Эконометрическая модель
- Классическая регрессия с интерпретируемыми коэффициентами
- **R² = 0.9999** (превосходное качество на обучающих данных)
- **Adjusted R² = 0.9998**

### 2. **Linear Regression** — Базовая ML модель
- **Train R² = 1.000**
- **Test R² = 0.546** (склонность к переобучению на малой выборке)
- **Test RMSE = 247,396** млн тенге

### 3. **Ridge Regression** — Регуляризация L2
- **Train R² = 0.996**
- **Test R² = -2.763** (отрицательный — плохая обобщающая способность)
- **Test RMSE = 712,397** млн тенге
- **Alpha = 1.0**

### 4. **Lasso Regression** — Регуляризация L1
- **Train R² = 0.9999**
- **Test R² = 0.890** ⭐ **ЛУЧШИЙ РЕЗУЛЬТАТ СРЕДИ ML МОДЕЛЕЙ**
- **Test RMSE = 121,525** млн тенге
- **Alpha = 0.1**

### 5. **ElasticNet** — Комбинация L1 + L2
- **Train R² = 0.994**
- **Test R² = -3.624** (плохая обобщающая способность)
- **Test RMSE = 789,665** млн тенге
- **Alpha = 0.5, L1 ratio = 0.5**

### 6. **ARIMA(1,2,1)** — Временные ряды ⭐ НОВОЕ
- **R² = 0.3026** (на исторических данных)
- **Подход:** Авторегрессионная интегрированная скользящая средняя
- **Преимущества:** 
  - ✅ Учитывает только тренд целевой переменной (не зависит от факторов)
  - ✅ Более консервативный прогноз
  - ✅ Хорош для краткосрочных прогнозов
- **Недостатки:**
  - ⚠️ На малых выборках (n=8) менее надежен
  - ⚠️ Не учитывает экзогенные факторы

> **Вывод:** Лучше использовать **комбинацию Lasso + ARIMA** (объединить мнение факторной модели и временного ряда)

## 🛠️ Технический Стек

**Библиотеки:**
- **Обработка данных:** pandas, numpy
- **Эконометрика:** statsmodels (OLS, ARDL)

- **Визуализация:** matplotlib, seaborn

- `scenarios.py` — Генерация сценариев на основе исторических трендов
- `time_series.py` — Временные ряды (ARIMA с auto grid search) ⭐ НОВОЕ

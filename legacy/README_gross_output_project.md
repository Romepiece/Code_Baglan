# Прогнозирование валового выпуска продукции сельского хозяйства

## Описание проекта
Проект посвящён прогнозированию валового выпуска продукции (услуг) сельского хозяйства
на основе многомерных социально-экономических и производственных показателей за 2015–2024 гг.

Исследование ориентировано на сценарный анализ и оценку влияния факторов инклюзивного развития
с использованием экономико-математических и машинных методов.

---

## Целевой показатель
**Валовый выпуск продукции (услуг) сельского хозяйства**.

---

## Данные
Используются годовые официальные статистические данные, включающие:
- показатели занятости и производительности в сельском хозяйстве;
- доходы и уровень жизни сельского населения;
- структуру землепользования;
- социальные и инклюзивные индикаторы.

Временной охват: **2015–2024 гг.**

---
## Единицы измерения данных

Используемый датасет содержит показатели, измеряемые в различных шкалах
(денежные значения, проценты, количественные показатели).
Единицы измерения каждого показателя приведены в файле `variables_mapping.md`.

При моделировании учитывается неоднородность шкал:
масштабирование применяется только для отдельных ML-моделей,
эконометрические модели оцениваются в исходных единицах.

## Методология
В исследовании применяется гибридный подход:
1. Эконометрический анализ временных рядов (тренды, сценарии).
2. Регрессионные ML-модели (Linear / Ridge / Lasso / ElasticNet).
3. Feature engineering для временных рядов (лаги, темпы роста, индексация).
4. Сценарное прогнозирование (пессимистичный, базовый, оптимистичный сценарии).
5. Интерпретация факторов и их относительной значимости.

Глубокие нейросетевые модели не используются в связи с ограниченным объёмом выборки.

---

## Структура проекта
- `data/` — `/raw/`исходные и `/processed/`обработанные данные  
- `notebooks/` — Jupyter Notebook с анализом и прогнозом  
- `prompts/` — промт для AI-ассистента (Copilot)  
- `figures/` — визуализации для статьи  

---

## Использование AI-инструментов
Для ускорения разработки и повышения воспроизводимости исследования
используется AI-ассистент (GitHub Copilot), работающий по заранее
зафиксированному промту (`prompts/copilot_prompt.md`).

AI используется как вспомогательный инструмент и не заменяет
методологические решения исследователя.

---

## Ограничения исследования
- короткий временной ряд (10 наблюдений);
- годовая агрегированность данных;
- прогнозы носят сценарный, а не детерминированный характер.

---

## Назначение
Проект предназначен для использования в научных публикациях,
магистерской / PhD-диссертации и аналитических отчётах.

# Результаты K-Means кластеризации регионов

## Методология
- Признаки кластеризации:
  - Среднее логарифмированное число женских фермерств
  - Стандартное отклонение женских фермерств
  - Среднее логарифмированное значение сельскохозяйственного кредита
  - Стандартное отклонение сельскохозяйственного кредита
  - Среднее значение доли земли
  - Тренд развития женских фермерств (линейный наклон по времени)

- Оптимальное число кластеров: K = 2 (по максимуму Silhouette Score)
- Метод стандартизации: StandardScaler
- Семя случайности: 42

## Оптимальность кластеризации
Silhouette Score по числу кластеров:
K=2.0: 0.3999
K=3.0: 0.2781
K=4.0: 0.2253
K=5.0: 0.2108
K=6.0: 0.1988

## Интерпретация

Кластеризация выявила 2 групп регионов с различными характеристиками развития женского предпринимательства в сельском хозяйстве:

**Кластер 0**: 15 регионов, с высоким уровнем женского предпринимательства, растущий тренд. **Кластер 1**: 5 регионов, с низким уровнем женского предпринимательства, растущий тренд.
